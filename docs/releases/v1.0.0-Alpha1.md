The first public alpha of OAmp, an open source music player for
[Navidrome](https://www.navidrome.org/). This is an early build for people
who are happy to try things out and report problems. Expect rough edges.

## Downloads

| Platform | File | Notes |
| --- | --- | --- |
| Windows 10/11 (x64) | `oamp-v1.0.0-Alpha1-windows-setup.exe` | Installer. Installs for your user, no admin needed. |
| Windows 10/11 (x64) | `oamp-v1.0.0-Alpha1-windows.zip` | Portable: unzip anywhere and run `oamp.exe`. |
| Android 7.0+ | `oamp-v1.0.0-Alpha1.apk` | Side-load. Allow installs from your browser or file manager when asked. |

Requires Navidrome v0.64.2 or later.

## What's in it

- **Sign in** with server address, username and password. OAmp uses token
  sign-in, so your password is never sent or stored.
- **Home** with one-tap Shuffle library and Liked tracks, plus rows of
  recently played, recently added, most played, liked and random albums.
- **Library**: artists and albums with an A to Z jump bar, playlists (create,
  rename, reorder and remove tracks) and liked tracks. Fast with large
  libraries.
- **Search** across artists, albums and tracks, with filters and recent
  searches.
- **Mini-player** and a full **now playing** screen tinted from the cover,
  with the queue underneath: drag to reorder, swipe to remove, jump to any
  track. Your queue is kept on the server, so it carries over between devices.
- **Lyrics** (synced where the server has them), **star ratings** and likes.
- **Playback settings**: gapless (Windows), crossfade, ReplayGain, streaming
  quality (separate for mobile data on Android) and a cache that loads the
  next tracks ahead of time.
- Plays are reported to Navidrome, so play counts and "recently played" stay
  current.
- **Windows**: a tall single-column window, or expanded mode with a library
  panel beside it. Shows in the Windows media overlay and lock screen, and
  the keyboard media keys work while OAmp is minimised. Keyboard shortcuts
  for play/pause, skip, volume and search.
- **Android**: keeps playing in the background with notification and lock
  screen controls, pauses for calls and other apps, pauses when headphones
  are unplugged, recovers from network drops, and has a landscape now playing
  layout.

## Before you install

- **Windows SmartScreen warning.** The Windows installer and app are not
  code-signed yet, so Windows may show "Windows protected your PC". Click
  **More info**, then **Run anyway**. Signing is planned for a later release.
- **Android test builds.** If you installed an OAmp test build from GitHub
  Actions, uninstall it once before installing this APK. Release builds are
  signed with a different key, so Android won't install one over the other.
  You'll need to sign in again afterwards.

## Known issues

- On Android, album tiles in the grid overflow when the system text size is
  set to 130% or larger.
- macOS and iOS builds are not available yet.

Please report problems at https://github.com/flatscan/oamp/issues.
